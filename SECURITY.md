# Política de seguridad

## Versiones compatibles

Se corrigen vulnerabilidades en la última versión publicada y en la rama `main`.

## Reportar una vulnerabilidad

No publiques detalles sensibles en un issue. Usa **Security → Report a vulnerability** en el repositorio de GitHub para crear un aviso privado:

https://github.com/Suggus1899/page_to_pdf/security/advisories/new

Incluye una descripción, pasos de reproducción, impacto estimado y, si es posible, una corrección propuesta. Se acusará recibo cuando el mantenedor revise el informe; la divulgación pública debe coordinarse después de disponer de una solución.

## Alcance

Son especialmente relevantes la exposición de contenido capturado, permisos excesivos, ejecución remota, escapes entre páginas y extensión, corrupción de IndexedDB o archivos PDF manipulados. Los fallos normales de presentación pueden informarse mediante issues públicos.
